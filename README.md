## О проекте

**WebXR Quest** — браузерная AR-игра, в которой интерактивные 3D-объекты размещаются в реальном окружении пользователя.

Для рендеринга и управления 3D-сценой используется **Three.js**, а для запуска дополненной реальности — **WebXR Device API**. Положение виртуальных объектов определяется относительно поверхности, найденной с помощью **WebXR Hit Test API**.

Игра состоит из нескольких последовательных заданий и включает систему прогресса, интерактивные объекты, анимации, звуковую обратную связь и DOM-интерфейс.

---

## Игровой процесс

Квест состоит из трёх этапов.

### 1. Найти ключ и сундук

Игрок исследует AR-сцену, находит ключ и взаимодействует с сундуком, размещённым в реальном пространстве.

### 2. Собрать монеты

Вокруг обнаруженной поверхности появляются монеты. Игрок должен найти и собрать их, чтобы перейти к следующему этапу.

### 3. Уничтожить объекты

На финальном этапе необходимо надуть шарики пока они не лопнут.

Во время прохождения интерфейс отображает текущее задание и игровой прогресс.

## Возможности

- AR-сцена на **Three.js**
- запуск дополненной реальности через **WebXR Device API**
- обнаружение поверхности с помощью **WebXR Hit Test API**
- размещение 3D-объектов относительно найденной поверхности
- процедурная генерация позиций объектов
- взаимодействие с объектами через события WebXR-ввода
- обработка касаний и кликов на мобильных устройствах
- трёхэтапная система прохождения квеста
- DOM-интерфейс с текущим заданием и счётом
- анимированные визуальные реакции объектов
- звуковая обратная связь
- использование примитивов и материалов Three.js для генерации объектов

## Как запустить

### Онлайн-версия

Откройте:

**https://aleksandralev.github.io/WebXR-Quest/**

AR-режим предназначен для запуска на **мобильном устройстве с поддержкой WebXR AR**.

Рекомендуемый способ запуска:

1. Откройте ссылку на мобильном устройстве.
2. Используйте браузер **Google Chrome**.
3. Разрешите браузеру доступ к камере.
4. Наведите камеру на ровную поверхность, чтобы приложение смогло её обнаружить.
5. Запустите AR-режим и следуйте заданиям на экране.

### Ошибка `AR Not Supported`/`WebXR Not Available`

Если приложение показывает сообщение:

```text
AR Not Supported
```
или
```text
WebXR Not Available
```

попробуйте следующее:

1. Убедитесь, что проект открыт на **мобильном устройстве**.
2. Откройте страницу через **Google Chrome**.
3. Отключите **VPN** и перезагрузите страницу.
4. Проверьте, что Chrome разрешён доступ к камере.

AR-режим проекта не предназначен для запуска в обычном браузере на ПК.
